# Security policy

This laboratory project does not process real credentials or require access to live equipment.
Please do not test it against systems you do not own or have explicit authorization to assess.

For a suspected vulnerability, use GitHub's private vulnerability reporting feature if enabled for
the repository. Include affected version, reproduction steps, impact, and any suggested mitigation.
Do not include production network configurations or secrets in the report. If private reporting is
unavailable, open a minimal issue asking the maintainer to enable a private channel without disclosing
the vulnerability details.

Only the latest release is intended to receive security fixes.
